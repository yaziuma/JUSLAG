# 市場間休日と前日比の定義（2026-09-17）

`scripts/reports/analyze_return_alignment.py`で、ローカル調整価格キャッシュ（2018-07-01から2026-09-17の直前まで）を使い、各市場の価格から先に前日比を計算する方法と、米日共通日に価格を絞ってから前日比を計算する方法を比較した。既知の1629.T価格異常は読み込み時に修復した。外部取得はしていない。

| 指標 | 結果 |
| --- | ---: |
| 米日共通価格日 | 1,937 |
| 米国のみ価格がある日 | 125 |
| 日本のみ価格がある日 | 73 |
| 前日比が異なる共通日 | 168 |
| 前日比が異なる銘柄・日セル | 2,168 / 比較可能54,176 |
| 米国側: 差がある日・セル | 97日・1,063セル |
| 日本側: 差がある日・セル | 72日・1,105セル |
| 差があるセルの平均絶対差 | 米国101.092bps、日本95.253bps |

例: 日本休場中に米国が1日取引された場合、市場別先行の米国前日比は直前の米国営業日からの変化のみ。共通日先行は直前の米日共通日からの累積変化となる。逆の休場でも同様。`build_joint_cc()`は市場別先行、外部実装と同条件の`compare_external_pca.py`は共通日先行なので、両者のPCA入力は休日明けに一致しない。

この集計は**入力の差**であり、論文準拠版の年率+8.31%と外部同条件版+6.454%の成績差を定量帰属したものではない。両比較には期間・日付対応等も異なる。なお本集計の共通日は各市場で少なくとも1銘柄の価格がある日で定義したため、`compare_external_pca.py`の代表銘柄XLK/1617.Tによる共通日1,936日とは1日異なる。約定可能性の証拠にもならない。

再現: `PYTHONPATH=src .venv/bin/python scripts/reports/analyze_return_alignment.py`。次は同じ共通日・同じ評価期間でPCA損益を両入力定義により再計算し、成績差の寄与を分ける。
