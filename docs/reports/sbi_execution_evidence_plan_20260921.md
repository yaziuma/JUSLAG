# SBI注文・受付・約定・売建・料金の証拠調査（2026-09-21）

## 結論

SBI証券に関する証拠を「未取得」と一括するのは不正確である。注文ルール、注文受付可能時間、一般信用売り・HYPER空売りの対象、HYPER料、建玉上限、貸株料、金利、通常売買手数料は、SBI証券の公開資料と日次銘柄一覧から調査・前向き保存できる。

一方、個別注文の受付番号、受付日時、約定日時、約定価格、約定数量、取消・失効・一部約定、口座別余力、実際に徴収された費用は、実注文後の口座内履歴・取引報告書が必要である。公開情報だけでは実約定を証明できず、実際に行わなかった過去注文の証拠を後から生成することもできない。

したがってA2では、以下を分離して保存する。

1. 実注文なしで取得可能な「公開条件証拠」
2. 明示承認された実注文を行った場合だけ取得可能な「口座・約定証拠」

公開条件の収集は実資金試験を意味せず、自動発注も許可しない。

## 公式情報から確認した条件

### 売買手数料

インターネットコースで電子交付等の条件を満たす「ゼロ革命」では、オンラインの国内現物・信用取引の通常売買手数料は0円。ただし金利、貸株料、HYPER料、強制返済等の費用は別である。

### 日計り信用と持越し

一般信用の日計り取引は、当日中に返済する通常銘柄について金利・貸株料0%と案内されている。当日中に決済しなかった場合、翌日以降は買方金利・貸株料とも年率1.80%が発生し、強制返済時には所定手数料が適用され得る。

### 売建可否と在庫

一般信用・日計り信用の売建はSBI証券が指定した銘柄に限られ、銘柄別上限株数がある。在庫不足時は建玉限度額内でも注文を受け付けられない。公開一覧で対象銘柄・上限を確認できても、口座別の注文可能数量と発注時点の最終可否はログイン後の画面で確認する必要がある。

### HYPER空売り

HYPER空売り銘柄、1株1日当たりのHYPER料、1人当たり建玉上限数は毎営業日見直され、19時頃に公表される。HYPER料は通常の貸株料とは別に発生する。持ち越した場合は、建株数、日次HYPER料、受渡ベースの持越し日数に応じた追加費用が発生する。

### 注文・約定履歴

SBI証券の取引履歴CSVには、受付番号、取引区分、受付日時、約定日時、約定価格、約定数量、新規建日、建単価、損益、最終決済日等が含まれる。約定履歴は口座管理画面から過去2年間を確認でき、電子交付書面は過去5年分がWEB保存されると案内されている。

## 2026-09-24から固定して保存する項目

### 公開条件スナップショット

原則として、翌営業日分が公表された後と発注想定時刻直前の両方を保存する。

- `evidence_date_jst`: 保存日
- `applicable_session`: 適用するJPX営業日
- `observed_at_jst`: 実取得時刻
- `source_url`: SBI公式ページ
- `source_sha256`: 取得本文または原ファイルのSHA-256
- `ticker`: 1617～1633
- `margin_type`: 制度／一般無期限／一般短期／日計り／HYPER
- `new_short_allowed`: 新規売建可否
- `hyper_short`: HYPER空売り対象か
- `hyper_fee_yen_per_share_day`: 1株1日当たりHYPER料
- `max_position_units`: 1人当たり建玉上限
- `published_at_or_label`: ページ記載の公表時刻・適用日
- `collection_status`: 取得成功／対象外／ログイン必要／解析不能

一覧に存在しないことだけで「売建不可」と断定しない。一般信用一覧、HYPER一覧、ログイン後の注文画面で意味が異なるため、情報源と取引区分を必ず併記する。

### 実注文を行う場合の口座証拠

実資金試験は別途明示承認を必要とする。承認された場合は、銘柄ごとに以下を保存する。

- 戦略run ID、対象営業日、シグナル方向
- 注文受付番号
- 送信時刻とSBI受付日時（秒単位）
- 市場、信用区分、執行条件、注文種別、指値・成行
- 注文数量、受付数量、約定数量、未約定数量
- 約定日時、約定価格、複数約定の全明細
- 取消・訂正・失効・拒否と理由
- 発注直前の売建可能数量、建玉上限、信用余力
- HYPER料、貸株料、金利、売買手数料、その他諸費用
- 取引報告書・履歴CSVの原本SHA-256
- 対応する寄り後バーと、代理価格との差

CSVや画面保存には口座番号、氏名、余力等の機微情報が含まれ得るため、Git、GitHub Actions artifact、Turso、Pagesへ原本を保存しない。リポジトリには匿名化した集計と原本ハッシュだけを保存する。

## A2判定への反映

- 公開条件60営業日の収集は、売建対象率、HYPER依存率、料金分布、建玉上限による注文不能率を推定する証拠になる。
- 公開一覧上の売建可能性だけでは、個人口座の在庫確保、注文受付、約定率、スリッページを証明しない。
- yfinanceの寄り後バーは市場価格の代理であり、SBI約定証拠ではない。
- A2のGoには、固定ゲートどおり、SBI由来の注文・受付・約定時刻、方向、数量、価格、売建可否・料金を含む明示承認済み試験が必要である。
- 公開条件の収集完了だけで`live_trading_allowed`を変更しない。
