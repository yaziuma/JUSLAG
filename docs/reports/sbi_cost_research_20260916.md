# SBI証券におけるJUSLAG執行コスト調査

- 調査日: 2026-09-16
- 対象: 国内上場TOPIX-17 ETFを寄りで建て、同日引けで返済するJUSLAG戦略
- 前提: SBI証券インターネットコース、オンライン注文、必要書面をすべて電子交付

## 結論

JUSLAGの現行バックテストに設定されている片道5bpsの委託手数料は、SBI証券のゼロ革命適用口座には過大である。国内株式の現物・信用取引の通常売買手数料は0円になる。

同日中に返済する一般信用の日計り取引は、通常銘柄なら金利・貸株料も0円である。したがって、通常の日計り売建在庫を確保できる場合の明示的な証券会社コストは原則0円となる。

一方、以下は0円ではない、または事前に確定できない。

- HYPER空売り対象銘柄の銘柄別HYPER料
- 売建在庫不足による注文不可または失効
- 当日中に返済できなかった場合の年率1.80%の貸株料・買方金利
- 強制返済時の所定手数料
- 市場のビッド・アスク・スプレッド、寄り・引けの約定ずれ、市場インパクト
- 制度信用を使う場合の年率1.10%の貸株料および逆日歩

## SBI証券の公式料金

| 項目 | JUSLAGで想定する取引 | 公式料金・条件 |
|---|---|---|
| 現物売買手数料 | LONGを現物で売買 | ゼロ革命適用時0円 |
| 信用売買手数料 | SHORTを信用新規売・返済買 | ゼロ革命適用時0円 |
| 日計り信用の貸株料 | 同日中にSHORTを返済 | 通常銘柄は0% |
| 日計り信用の金利 | LONGを信用買いする場合 | 同日返済なら0% |
| HYPER料 | 通常の日計り売建ができない銘柄 | 銘柄別・日々変動、ログイン後の注文画面で確認 |
| 期日超過 | 当日中に返済できない場合 | 翌日以降、買方金利・貸株料とも年率1.80% |
| 制度信用貸株料 | 日計りではなく制度信用を利用 | 年率1.10%、逆日歩が発生する場合あり |

## 現行モデルとの差

現行設定は、手数料5bpsとスリッページ5bpsをそれぞれ片道で控除している。LONG 100%とSHORT 100%を毎日往復すると、手数料だけで約50.4%/年、スリッページも約50.4%/年となり、合計の年率低下幅は100.8ポイントになる。

SBI証券のゼロ革命を前提にすると、手数料は0bpsへ変更するのが妥当である。日計り信用の通常売建が可能な銘柄については、貸株料も0%にできる。

ただしスリッページ5bpsはSBI証券の料金ではなく、市場執行コストの仮定である。これを0にしてはならない。TOPIX-17 ETFは銘柄ごとの流動性が異なるため、寄り・引けの気配、約定価格、売買数量を保存し、実績から推定する必要がある。

単純試算では、手数料だけを0bpsにし、スリッページ5bps/片道を維持すると、年率コストは約100.8%から約50.4%へ下がる。2026-09-16のGross年率26.57%に単純適用しても約-23.83%であり、手数料修正だけでは実用化できない。売買回転率の削減も必要である。

## 実装へ反映すべき条件

1. SBIゼロ革命プロファイルでは `commission_bps_per_side=0` とする。
2. 日計り信用かつ通常売建可能なら `short_borrow_rate_annual=0` とする。
3. HYPER銘柄は固定年率ではなく、銘柄別の1口1日料金として扱う。
4. 売建在庫がない銘柄は注文候補から除外する。
5. スリッページは固定値だけでなく、銘柄・日付別の寄り引け約定データで検証する。
6. 制度信用へフォールバックする場合は貸株料1.10%と逆日歩を別シナリオで評価する。
