市場別先行マイナス共通日先行は年率+0.108ポイント。日次損益が異なるのは380日で、絶対差の平均は10.197bps、最大316.771bps。平均差は小さいが、個別日の判断や損益は変わり得る。コストは同一の定額仮定なので、ネット差も+0.108ポイントである。税・売建可否・実約定は含まない。
