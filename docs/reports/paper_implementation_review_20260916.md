## 1. 結論

現行実装の部分空間正則化PCA、事前部分空間、米国リターンから日本シグナルへの写像、上下30%の等ウェイトロング・ショートという中核は、論文の式(8)～(21)と概ね一致する。

ただし、現在本番で判定対象になっている `PCA SUB + rule_406_no_flip` は論文の戦略ではない。さらにメタ戦略のバックテストには先読みバイアスと寄り付きギャップの日付不整合がある。その成績を根拠に実資金を投入できる状態ではない。

実現性は次のように評価する。

| 用途 | 評価 | 理由 |
|---|---|---|
| 論文アルゴリズムの研究再現 | 条件付きで可能 | 中核数式は実装済み。ただし論文側にも欠損処理・実効期間の曖昧さがある |
| 日次の参考シグナル生成 | 可能 | 米国終値後から日本寄り前に計算可能 |
| SBI証券での手動執行 | 条件付きで可能 | 空売り在庫、HYPER料、寄り引け約定、必要信用余力の確認が必要 |
| 現行Judgeによる実資金運用 | 不可 | メタ戦略検証の先読み、時点不整合、価格系列差、実約定検証不足 |
| 完全自動売買 | 未実装 | 発注、約定、建玉、余力、在庫、損失上限の制御がない |

## 2. 論文の戦略仕様

論文が定義する主な条件は以下である。

- 米国: Select Sector SPDR 11業種ETF
- 日本: NEXT FUNDS TOPIX-17 業種別ETF 17銘柄
- 入力: 米国当日Close-to-Closeリターンと日米の過去Close-to-Closeリターン
- 予測対象: 日本の翌営業日Open-to-Closeリターン
- 推定窓: `L=60`
- 因子数: `K=3`
- 正則化係数: `lambda=0.9`
- 事前部分空間: グローバル、国スプレッド、シクリカル・ディフェンシブの3方向
- 銘柄選択: シグナル上位30%をロング、下位30%をショート
- ウェイト: ロング側合計 `+1`、ショート側合計 `-1` の各側等ウェイト
- グロス想定元本: 2、ネット想定元本: 0
- 価格: 株式分割・分配金を調整したOpen/Close系列
- 記載サンプル: 2010年1月～2025年12月
- `Cfull` 推定期間: 2010年1月1日～2014年12月31日
- 論文報告値（PCA SUB）: AR 23.79%、Risk 10.70%、R/R 2.22、MDD 9.58%

論文の報告値は売買コスト、スリッページ、借株制約、税、約定不能を反映した実運用収益ではない。

## 4. 重大な問題

### 4.1 メタ戦略のレジーム分類に先読みバイアスがある

`src/juslag/regime.py` の `_classify_quantile()` は、全期間の `vol20` と `rotation_std` から25%・75%分位点を一度に計算し、その閾値で過去の各日を分類する。バックテスト時点より後の観測値が過去の `high_vol` / `weak_rotation` 判定へ入る。

`rule_406_no_flip` は `weak_rotation` を取引除外条件に使うため、現行Judgeが評価するメタ戦略成績は先読みの影響を受ける。分位点は各日までのexpanding、または過去固定長rollingで計算し、最低でも1日shiftする必要がある。

**重大度: Critical**

### 4.2 寄り付きギャップの日付がバックテストと実運用で一致しない

バックテストはシグナル日 `t` に対して利益を日本の次の共通取引日 `t+1` から取得する一方、メタルールへ渡すギャップは `overnight_gap_df.loc[t]` である。利益対象日の寄り付きギャップではなく、原則として1取引日前のギャップを使っている。

日次処理では執行対象日のOpenがまだ存在しない場合、`pick_overnight_gap()` が最新行へフォールバックする。平日08:00 JSTの実行時には当日09:00のOpenは未確定なので、表示上の「寄りgap制限」は前営業日の値になる。

執行日Openを使うなら09:00以降に判断する必要があり、そのOpen価格で約定した前提は成立しにくい。08:00判断を維持するなら、当日ギャップ依存ルールを廃止するか、気配・先物など事前に観測可能な情報へ定義を変更すべきである。

**重大度: Critical**

### 4.3 本番シグナルが論文と異なる生価格を使用する

論文は分割・分配金調整済み価格を明記する。実装は調整済み系列を取得できるが、日次シグナルは `price_mode="raw"` に固定されている。分配落ちや分割がClose-to-Closeリターンへ人工的なショックとして入り、60日窓の相関と当日シグナルを汚染する。

シグナル生成と論文比較はadjusted系列へ統一し、実際の発注金額だけraw価格を使うべきである。

**重大度: High**

### 4.4 検証期間と事前学習期間が論文と異なる

論文は2010～2014年で `Cfull` を推定し、その後を評価する。現行設定は2018-07-01～2021-12-31を事前学習、2022年以降を評価する。これは別実験であり、論文のAR 23.79%との直接比較はできない。

一方、論文自身にも再現上の曖昧さがある。XLCは2018年設定、XLREは2015年設定であり、表1の観測数も全銘柄で揃っていない。それにもかかわらず2010～2014年の28銘柄完全な `Cfull` をどう構成したか、銘柄欠損をどう扱ったかが本文から確定できない。著者コードまたは補足説明がない限り厳密再現ではなく「論文準拠再実装」と表示すべきである。

**重大度: High**

### 4.5 空売り可能性を静的に無視している

現行本番想定は `allow_short=true`、`short_constraint_mode=ignore`、借株料0で、全ショート候補を毎日売れるものとして扱う。SBIの日計り信用は通常銘柄なら売買手数料・貸株料0になり得るが、一般信用売建在庫は日々変動し、HYPER銘柄には銘柄別HYPER料が発生する。

取引前に銘柄別在庫とHYPER料を取得・記録し、売建不可なら除外後にウェイトを再配分する必要がある。現状のバックテストには履歴在庫データがなく、ショート側の実現可能性を再現できない。

**重大度: High**

## 5. その他の実装差・リスク

### 5.1 取引日の整列

`build_joint_cc()` は日米の同一カレンダー日だけをinner joinし、完全ケースへ落とす。論文の「共通に観測可能な営業日のみ」と整合的ではあるが、日米どちらか一方だけ開場した日を飛ばす。`shift(-1)` は「次の日本営業日」ではなく「次の共通観測日」になる場合がある。JPXとNYSEのカレンダーを別に持ち、米国シグナル時刻から最初のJPX取引日へ明示的に対応付ける方が安全である。

### 5.2 シグナル閾値は論文外

`min_long_signal >= 0`、`max_short_signal <= 0`、adaptive threshold、最少採用数は論文にない拡張である。現在値が0でも符号フィルタとして働くため、上位・下位分位を必ず採用する論文戦略とは異なる日がある。

### 5.3 メタ戦略は論文外かつ多重探索の影響が不明

寄りgap、rotation、volatility、反転、年次選択など複数ルールを後付けで比較している。独立した完全アウト・オブ・サンプル期間、選択候補数を考慮した多重検定、walk-forwardでのルール固定がない限り、改善値はデータスヌーピングの可能性が高い。

### 5.4 コストモデルは概算

5bps/sideのスリッページはSBI手数料ではなく仮定である。売買代金、板、始値・終値オークションの出来高、スプレッド、注文参加率を使っていない。グロス2倍を毎日往復するため、5bps/sideでも戦略全体では概ね20bps/取引日の負担になる。現行結果でコスト控除後収益が大幅に悪化する主因である。

### 5.5 発注数量は資金制約を入力していない

日次プランは最低購入額の最大値へ各銘柄を丸めて揃えるだけで、口座資産、信用建余力、最大グロス、銘柄上限、現金バッファを入力しない。表示数量は「最小の等金額例」であり、実運用ポートフォリオではない。

### 5.6 税モデルは会計上の近似

年次税モデルは日次リターンを単純加算して課税所得を作る。実現損益、建玉元本、手数料、配当、口座区分、損益通算を管理する台帳ではない。投資判断の主成績は税引前とし、税引後は参考値に留めるべきである。

### 5.7 論文の年率式にも確認事項がある

本文式(27)(28)は抽出上 `12` に見える一方、戦略リターンは日次と記載されている。現行実装は252営業日で年率化しており一般的には妥当だが、論文表2を厳密再現するには著者へ年率係数とリターン頻度を確認する必要がある。

## 6. 実運用へ進むための優先順位

1. レジーム分位点を過去情報のみのwalk-forward計算へ修正する。
2. ギャップ特徴量の観測時刻と利益対象日を定義し直し、バックテストと日次処理を同一仕様にする。
3. 論文準拠ベースラインをadjusted価格、メタルールなし、閾値なしで独立出力する。
4. 論文準拠結果と本番拡張結果をJudge・UI上で完全に分離する。
5. JPX/NYSEカレンダーによるイベント時刻ベースの対応付けを実装する。
6. SBI売建在庫・HYPER料を日次スナップショットとして保存し、発注可能銘柄だけで再計算する。
7. 実約定または板データから銘柄別・売買時間帯別のスリッページを推定する。
8. 資産額、信用余力、最大グロス、銘柄上限、日次損失上限を含むサイジングを実装する。
9. 変更後に期間を触らず、一定期間ペーパートレードして予測値と実約定可能損益を照合する。

## 7. 判定

論文の着想とPCAコアには実装可能性がある。米国市場終了後に情報を確定し、日本市場の寄り前にクロスセクション順位を作る処理も時間上は可能である。

しかし、論文の高いグロス成績が実コスト後にも残ることは現行結果では確認できない。加えて、現在の最終Judgeが採用するメタ戦略には検証上のCriticalな問題がある。したがって、現時点の実用判定は「研究・ペーパートレード継続、実資金投入は保留」とする。
