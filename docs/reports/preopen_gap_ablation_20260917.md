# 寄りgap除外アブレーション（2026-09-17）

## 目的と方法

現行`rule_406_no_flip`は当日JP寄りgapで日次見送り・銘柄除外を決め、同じ寄り値から引けまでの損益を計上する。この意思決定は08:00 JSTには不可能で、寄りを見てから同値で約定できる保証もない。そこで研究用`research_preopen_no_gap`を作り、弱rotation除外だけを残し、当日gapの利用を日次・銘柄レベルともに除いた。PCAシグナル、価格系列（raw）、評価開始2022-01-01、上下分位、符号閾値、片道スリッページ5bps、税設定は同一。両者とも翌JP寄り→引け、片道5bpsのモデル約定であり、実約定の検証ではない。

`scripts/reports/compare_preopen_baseline.py`をローカル価格キャッシュのみで実行。再現用設定は`JUSLAG_BACKTEST_SETTINGS_JSON`に本番適用のJSONを渡す。研究用ルールは本番レジストリに登録せず、日次発注にも使わない。

## 日別差分の内訳

両系列の日別取引明細を同じシグナル日で突き合わせた。現行版の701日はすべて寄りgapなし版にも含まれ、寄りgapなし版だけに89日ある。以下の差は「現行−寄りgapなし」の単純日次リターン合計であり、複利年率ではない。

| 区分 | 日数 | グロス差の合計 | 税前差の合計 |
| --- | ---: | ---: | ---: |
| 共通取引日 | 701 | +11,956.16bps | +12,166.16bps |
| 現行版のみ | 0 | 0 | 0 |
| 寄りgapなし版のみ | 89 | -554.51bps | +1,225.49bps |

共通701日の1日平均グロスは現行+21.86bps、寄りgapなし+4.80bps。税前では現行+2.16bps、寄りgapなし-15.20bps。共通日では日次見送り条件の差がないため、主な差は当日gapを見た銘柄除外とそれに伴うウェイト・コストの変化にある。追加89日は寄りgapなし版のグロス合計が+554.51bpsだが、税前合計は-1,225.49bpsで、往復コストに負けている。

この分解は記述的なもので、因果効果や約定可能収益ではない。共通日の優位性こそ同じ寄り値約定の非現実的な前提に依存する可能性が高い。`/tmp/juslag_preopen_comparison.json`に実行時の詳細集計を保存した（一時ファイル）。

## 解釈

- 寄りgapなし版はコスト前にはプラスでも、年率約50ポイント相当の往復コストに耐えない。現在の仮定での実用性はない。
- 成績差は寄りgapによる日次選別と銘柄除外の合成効果。日別分解では共通取引日の差が大きく、銘柄除外の寄与が中心。差額全部を先読みバイアスと断定できない一方、現行版のプラス成績は同値約定できない可能性があり、優位性の証拠として採用できない。
- 寄りgapなし版も寄り成行が理論上可能というだけで、寄り付き板・約定量・売建在庫・HYPER料・実スリッページは未検証。現行価格キャッシュも新規取得せず、過去データの追加取得ではない。
- これは既知期間を見た後の探索的アブレーションであり、独立した将来期間のウォークフォワード検証ではない。実運用ルールへの昇格はしない。

次に試すなら、寄り後の板・約定データを得て「gap確定後に発注できる価格」で現行ルールを再計算するか、日中往復を避ける低回転案を資金制約込みで別戦略として評価する。日次OHLCだけでは前者を正しく推定できない。
