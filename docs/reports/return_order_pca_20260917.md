# 前日比算出順序のPCA損益感度（2026-09-17）

`compare_return_order_pca.py`で、調整価格・既知の1629.T修復・共通日パネル・同じ評価日・同じ寄り→引け損益を固定し、前日比を「各市場で計算後に共通日化」と「共通日化後に計算」の2通りで比較した。共通日は外部比較と同じXLK/1617.Tの価格日で定義した。両方式で欠損のない同一行のみ使い、priorは共通日方式の事前学習値に固定した。変更したのはPCAのローリング入力と当日米国入力の前日比だけである。

| 指標 | 共通日先行 | 市場別先行 |
| --- | ---: | ---: |
| 同一評価日数 | 1,105 | 1,105 |
| グロス単純平均年率 | +6.352% | +6.460% |
| 5bps/side・両側グロス2の日中往復コスト後 | -44.048% | -43.940% |

市場別先行マイナス共通日先行は年率+0.108ポイント。日次損益が異なるのは380日で、絶対差の平均は10.197bps、最大316.771bps。平均差は小さいが、個別日の判断や損益は変わり得る。コストは同一の定額仮定なので、ネット差も+0.108ポイントである。税・売建可否・実約定は含まない。

以前の「論文準拠版+8.31%と外部同条件版+6.454%」という値の差は、少なくともこの**前日比算出順序だけ**では説明できない。今回の共通日先行+6.352%も外部比較の+6.454%と完全一致しない。今回のprior固定、完全観測行への制限、評価日数1,105日という条件は外部比較の1,106日と異なるため、残差を別要因へ断定していない。本番側の+8.31%とも、同じ日付・同じ価格パネル・同じpriorで対にした比較ではない。

再現: `PYTHONPATH=src .venv/bin/python scripts/reports/compare_return_order_pca.py`。次は本番の論文準拠系列とこの固定パネル系列の対象日・prior・損益対応を突き合わせる。現行メタ戦略の当日寄りgap同値約定問題は未解消で、いずれも実運用の根拠にはならない。

## 追試: 執行日の選び方

同じ市場別先行の前日比・共通日prior・シグナルを固定し、寄り→引け損益を「次の米日共通日」または「次の日本営業日」で対応付けた。評価はシグナル日2022-01-01以降の共通1,103日で行う。これは上表の**執行日ベース1,105日**とは母集団が異なるため、上表との差をそのまま加算しない。

| 執行日 | グロス単純平均年率 |
| --- | ---: |
| 次の米日共通日 | +6.155% |
| 次の日本営業日 | +8.095% |

43シグナルで執行対象日が異なり、その43日の損益だけが変わった。差は+1.940ポイント/年。従来の本番論文準拠版+8.31%と外部同条件版+6.454%の約1.86ポイント差には、**執行日カレンダーの違いが大きく寄与する**と推測できる。ただし、2つの過去集計は評価日数・prior・完全観測行の扱い等が揃っておらず、この追試だけで差の全量を厳密に帰属できない。

特に米国休場・日本開場の日、次の日本営業日は次の米日共通日より早い。外部同条件比較は共通日パネルだけで寄り→引けを評価し、本番バックテストは次の実際の日本価格行を使う。どちらを論文再現の定義とするかと、シグナル時点で利用可能な米国データを分けて明示する必要がある。過去の共通日同値比較が本番+8.31%を再現しなかった主因候補はこの執行日差である。

## 本番論文準拠系列との照合

ローカルキャッシュから本番の論文準拠処理（市場別前日比、`build_joint_cc`でprior学習、次の日本価格行で寄り→引け、評価開始2022-01-01）を同じ関数で再構成した。グロス年率+8.309%、1,104シグナル日となり、既存レポートの+8.31%・1,104日を再現した。外部取得はしていない。

上節の固定パネル・次の日本営業日版と共通の1,103シグナル日で比べると、本番版が年率+0.112ポイント高く、日次損益が異なるのは23日、日次絶対差の平均は0.369bps。固定パネル版は共通日priorを固定し、両入力方式で完全観測できる行へ絞っている。本番版は市場別前日比からpriorを学習し、独自の完全観測行を使う。この比較は両要因をまだ分離していない。また、本番版だけに末尾の1シグナル日があり、次の共通価格日がない一方で次の日本価格日はある。この日も全体年率差に影響する。

したがって、約1.86ポイントの過去の差について「前日比順序のみが原因」とは言えず、執行日の選択が大きな要因で、残りはprior/観測行/末尾の差と整理できた。ただし過去2系列そのものを同日ペアで厳密に分解したわけではない。特に末尾の未対になる日を含めた単純な年率差の加法分解は避ける。
